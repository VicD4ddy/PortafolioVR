# Portfolio Enhancer Skill

Use this skill when refining, styling, or adding new features to Víctor Reyes's developer portfolio.

## Capabilities & Workflows

1. **Aesthetic Auditing**:
   - Verify that all components use theme tokens from `src/index.css`.
   - Ensure high contrast ratios for readability in dark mode.
   - Validate that glassmorphism effects (`backdrop-blur-md`, subtle border alpha) look clean.

2. **Project Showcasing**:
   - For every new project added to `src/data/portfolioData.ts`, provide:
     - Clear category and technical stack tags.
     - Quantifiable impact metrics (e.g., latency, conversions, user growth, query speeds).
     - Direct links to the GitHub repository and live deployment if available.

3. **Motion & Interaction Tuning**:
   - Check modal animations (smooth fade & scale).
   - Ensure buttons provide immediate visual feedback (`active:scale-95`).
   - Keep interactions accessible and non-intrusive.
